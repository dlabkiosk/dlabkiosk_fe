# 통합 태그 처리 플로우

> **API**: `POST /api/v1/kiosk/tag`
> **최종 갱신**: 2026-03-20

---

## 카드/QR 태그 시 처리 흐름

```
카드 태그
  │
  ├─ 등원 전 ─────────────────────────────────────────┐
  │   ├─ 등원시간 전 → ✅ 등원 처리                      │
  │   └─ 등원시간 후 → ✅ 지각(등원) 처리                 │
  │                                                    │
  ├─ 등원 후 (하원시간 전) ────────────────────────────┐ │
  │   ├─ 외출/조퇴 신청 내역 있음                       │ │
  │   │   └─ ✅ 외출 또는 조퇴 처리                     │ │
  │   ├─ 외출/조퇴/좌석이탈 상태에서 태그                │ │
  │   │   └─ ✅ 복귀 처리                              │ │
  │   └─ 신청 내역 없음                                │ │
  │       └─ ❌ "신청내역이 없습니다. 데스크로 문의하세요" │ │
  │                                                    │ │
  └─ 하원시간 이후 ────────────────────────────────────┘ │
      ├─ 외출/좌석이탈 내역 있음                          │
      │   └─ ✅ 복귀 처리 → 하원 처리 (순차)              │
      └─ 외출/좌석이탈 내역 없음                          │
          └─ ✅ 하원 처리                                │
                                                        │
```

---

## 상세 규칙

### 1. 등원 처리

| 조건 | 결과 |
|------|------|
| 등원시간 전 + 미등원 | 등원 처리 |
| 등원시간 후 + 미등원 | 지각(등원) 처리 |
| 이미 등원 상태 | 등원 처리 안 함 → 아래 2번으로 |

### 2. 등원 후 태그 (하원시간 전)

| 조건 | 결과 |
|------|------|
| DSA 외출/조퇴 승인 내역 있음 | 외출 또는 조퇴 처리 |
| 외출/조퇴/좌석이탈 상태 | 복귀 처리 |
| 아무 신청 내역 없음 | "신청내역이 없습니다. 데스크로 문의하세요." |

### 3. 좌석이탈 신청

| 조건 | 결과 |
|------|------|
| 미등원 상태에서 좌석이탈 신청 | ❌ "등원처리를 먼저 해주세요." |
| 등원 상태에서 좌석이탈 신청 | ✅ 좌석이탈 처리 |

### 4. 하원 처리 (하원시간 이후)

| 조건 | 결과 |
|------|------|
| 외출/좌석이탈 내역 있음 | 복귀 처리 후 → 하원 처리 (순차) |
| 외출/좌석이탈 내역 없음 | 바로 하원 처리 |

---

## 처리 주체

| 규칙 | 처리 위치 |
|------|----------|
| 시간 기반 분기 (등원시간/하원시간) | **백엔드** |
| DSA 외출/조퇴 승인 내역 확인 | **백엔드** (DSA 연동) |
| 복귀 → 하원 순차 처리 | **백엔드** |
| 좌석이탈 시 등원 여부 체크 | **백엔드** |
| 응답 결과 화면 표시 | **프론트엔드** (키오스크) |
| actionLabel / messages 표시 | **프론트엔드** (키오스크) |

---

## 프론트엔드 표시 규칙

백엔드 `TagResult` 응답 기반으로 표시:

```
성공 시:
  "{studentName} 학생"
  "{actionLabel} 처리 되었습니다."
  [학생 메시지 표시 (messages 배열)]
  [pendingActions 버튼 (있을 경우)]

실패 시:
  에러 메시지 표시 (ERROR_MESSAGES 매핑)
```

### action 코드 → 한글 매핑

| action | 라벨 |
|--------|------|
| S | 등원 |
| O | 하원 |
| D | 외출 |
| R | 복귀 |
| C | 조퇴 |
| M | 급식 |

---

## 현재 상태 vs 목표

| 항목 | 현재 | 목표 |
|------|------|------|
| 등원 후 태그 | "하원 하시겠습니까?" pendingAction | 외출/조퇴 내역 확인 → 없으면 안내 메시지 |
| 하원시간 판단 | 프론트에 없음 (백엔드 판단) | 백엔드에서 시간 기반 분기 |
| 지각 처리 | 미확인 | 백엔드에서 등원시간 기준 판별 |
| 좌석이탈 등원 체크 | 미확인 | 백엔드에서 등원 여부 검증 |
| actionLabel null | fallback 추가 완료 | 백엔드에서 값 채워서 응답 |
