## 1. 로그인 / 회원가입

### 로그인

```
┌────────────────────────────────┐
│                                │
│         대성 관리자 로그인       │
│                                │
│  아이디:  [________________]   │
│  비밀번호: [________________]   │
│                                │
│  ☐ 로그인 상태 유지             │
│                                │
│         [로그인]                │
│                                │
│  비밀번호를 잊으셨나요?          │
│  회원가입                       │
│                                │
└────────────────────────────────┘
```

1. **아이디**와 **비밀번호**를 입력합니다.
2. **"로그인 상태 유지"** 체크박스를 선택하면 세션이 유지됩니다.
3. **[로그인]** 버튼을 클릭합니다.
4. 인증 성공 시 대시보드로 이동합니다.
5. 인증 실패 시 오류 메시지가 표시됩니다.

### 회원가입

```
┌────────────────────────────────┐
│                                │
│          회원가입                │
│                                │
│  이름:       [________________] │
│  아이디:     [________________] │
│  비밀번호:   [________________] │
│  비밀번호 확인: [________________] │
│                                │
│         [가입하기]              │
│                                │
└────────────────────────────────┘
```

1. **이름**, **아이디**, **비밀번호**, **비밀번호 확인**을 입력합니다.
2. 비밀번호는 **8자 이상**이어야 합니다.
3. 비밀번호와 비밀번호 확인이 일치해야 합니다.
4. **[가입하기]** 버튼을 클릭합니다.
5. 가입 성공 시 로그인 페이지로 이동합니다.

### 세션 관리

- 로그인 후 세션 정보(이름, 지점명, 권한)가 저장됩니다.
- **401 오류**(인증 만료) 발생 시 자동으로 토큰 갱신을 시도합니다.
- 갱신 실패 시 로그인 페이지로 이동합니다.
- **로그아웃** 시 세션이 초기화되고 로그인 페이지로 이동합니다.

## 2. 전체 화면 구성

```
┌──────┬─────────────────────────────────────────┐
│      │  [검색바]                    [관리자명]   │  ← 상단 네비게이션 바
│ 사   ├─────────────────────────────────────────┤
│ 이   │                                         │
│ 드   │                                         │
│ 바   │            메인 콘텐츠 영역              │
│      │                                         │
│ 메   │                                         │
│ 뉴   │                                         │
│      │                                         │
└──────┴─────────────────────────────────────────┘
```

### 사이드바 메뉴

| 순서 | 메뉴명 | 경로 | 설명 |
|------|--------|------|------|
| 1 | 대시보드 | `/` | 일일 운영 현황 요약 |
| 2 | 출결 관리 | `/attendance` | 학생 출결 조회/QR 관리 |
| 3 | 식사 신청 및 체크명단 | `/meals` | 급식 신청/체크 관리 |
| 4 | 휴대폰 미소지 관리 | `/phones` | 휴대폰 미소지 신청 관리 |
| 5 | 좌석 이탈 관리 | `/seat-leaves` | 좌석 이탈 현황/강제 복귀 |
| 6 | 좌석 관리 | `/seats` | 좌석 배치도/변경 요청 |
| 7 | 순공 관리 | `/study-time` | 일별 순공시간 조회 |
| 8 | 공지 관리 | `/notices` | 공지사항 CRUD |
| 9 | 설정 | `/settings` | 시스템 설정 (7개 탭) |

- 사이드바는 **접기/펼치기** 가능하며, 상태가 브라우저에 저장됩니다.
- 현재 선택된 메뉴가 강조 표시됩니다.

### 상단 검색바

- 페이지 이름과 주요 키워드로 **글로벌 검색**이 가능합니다.
- **키보드 단축키:** 위/아래 화살표로 결과 탐색, Enter로 선택, Escape로 닫기
- 검색 결과를 클릭하면 해당 페이지로 이동합니다.

## 3. 대시보드

로그인 후 가장 먼저 표시되는 화면으로, 지점의 일일 운영 현황을 한눈에 확인할 수 있습니다.

### 화면 구성

```
┌─────────────────────────────────────────────────────┐
│  [지점 선택 ▼] (ADMIN 전용)                          │
├─────────────┬──────────────┬────────────────────────┤
│             │              │                        │
│  등록 학생   │  금일 출석    │  식사 신청              │
│    52명     │    38명      │    30명                │
│             │              │                        │
├─────────────┴──────────────┴────────────────────────┤
│                                                     │
│  ── 출결 현황 요약 ──                    [더보기 →]  │
│  출석: 38명 | 조퇴: 2명 | 결석: 12명                 │
│  외출: 3명  | 지각: 1명                              │
│                                                     │
├──────────────────────┬──────────────────────────────┤
│                      │                              │
│  ── 좌석 이탈 현황 ── │  ── 식사 태그 현황 ──         │
│  금일 이탈: 5건       │                              │
│  미복귀: 2건         │  홍길동  중식  12:30          │
│       [더보기 →]     │  김철수  석식  18:15          │
│                      │  이영희  중식  12:25          │
│                      │  ...    (최근 5건)            │
├──────────────────────┼──────────────────────────────┤
│                      │                              │
│ ── 좌석 변경 신청 ──  │  ── 공지사항 ──              │
│                      │                              │
│ 홍길동 A-1→B-3 4/10  │  1. 중간고사 일정   4/10     │
│ 김철수 B-2→A-5 4/9   │  2. 주차장 안내     4/8      │
│ ...   (최근 5건)     │  3. 시간표 변경     4/5      │
│       [더보기 →]     │  ...    (최근 5건)            │
│                      │                              │
└──────────────────────┴──────────────────────────────┘
```

### 상단 카드 영역

| 카드 | 표시 내용 |
|------|----------|
| **등록 학생** | 지점에 등록된 전체 학생 수 |
| **금일 출석** | 오늘 출석(등원)한 학생 수 |
| **식사 신청** | 오늘 급식 신청한 학생 수 |

### 출결 현황 요약

- **출석, 조퇴, 결석, 외출, 지각** 인원이 각각 표시됩니다.
- **[더보기]** 클릭 시 출결 관리 페이지(`/attendance`)로 이동합니다.

### 좌석 이탈 현황

- **금일 이탈 건수**와 **미복귀 건수**가 표시됩니다.
- **[더보기]** 클릭 시 좌석 이탈 관리 페이지(`/seat-leaves`)로 이동합니다.

### 식사 태그 현황

- 최근 **5건**의 급식 태그 기록이 표시됩니다.
- 표시 정보: 학생 이름, 식사 유형(중식/석식), 태그 시간

### 좌석 변경 신청현황

- 최근 **5건**의 좌석 변경 신청이 표시됩니다.
- 표시 정보: 학생 이름, 현재 좌석 → 희망 좌석, 신청일
- **[더보기]** 클릭 시 좌석 관리 대기 뷰(`/seats?view=waiting`)로 이동합니다.

### 공지사항

- 최근 **5건**의 공지가 표시됩니다.
- 표시 정보: 번호, 제목, 작성일
- 공지를 클릭하면 해당 공지 상세 페이지로 이동합니다.

### ADMIN 전용: 지점 필터

- **ADMIN** 권한인 경우 상단에 지점 선택 드롭다운이 표시됩니다.
- **"전체"**를 선택하면 모든 지점의 합산 데이터가 표시됩니다.
- 특정 지점을 선택하면 해당 지점 데이터만 표시됩니다.

## 4. 출결 관리

학생들의 출결 현황을 조회하고 QR 코드를 관리하는 페이지입니다.

### 필터 옵션

```
┌─────────────────────────────────────────────────────────────┐
│  [지점 ▼]  [학생명 ____]  [학번 ____]                        │
│  [출결상태 ▼]  [휴대폰 ▼]          [검색]  [초기화]          │
└─────────────────────────────────────────────────────────────┘
```

| 필터 | 옵션 | 설명 |
|------|------|------|
| **지점** | 드롭다운 (ADMIN 전용) | 전체 또는 특정 지점 선택 |
| **학생명** | 텍스트 입력 | 학생 이름으로 검색 |
| **학번** | 텍스트 입력 | 학번으로 검색 |
| **출결상태** | 전체, 등원, 미출석, 외출, 하원, 공석, 미확인, 좌석이탈 | 특정 상태만 필터링 |
| **휴대폰** | 전체, O, X | 휴대폰 미소지 여부로 필터링 |

- **[검색]**: 입력한 조건으로 검색 실행
- **[초기화]**: 모든 필터를 기본값으로 리셋

### 테이블 컬럼

| 컬럼 | 정렬 | 설명 |
|------|------|------|
| **☐** | - | 체크박스 (전체 선택/개별 선택) |
| **지점** | - | 소속 지점명 (ADMIN 전용) |
| **학생명** | ✅ | 학생 이름 |
| **학번** | ✅ | 학번 |
| **좌석** | ✅ | 배정된 좌석 번호 |
| **출결상태** | ✅ | 색상 배지로 표시 |
| **휴대폰** | ✅ | O 또는 X 표시 |

### 출결상태 배지 색상

| 상태 | 색상 |
|------|------|
| 등원 | 🟢 초록 |
| 미출석 | 🔴 빨강 |
| 외출 | 🟡 노랑 |
| 하원 | ⚪ 회색 |
| 공석 | ⚪ 회색 |
| 좌석이탈 | 🟠 주황 |

### 행 클릭: QR 코드 모달

테이블의 행을 클릭하면 해당 학생의 **QR 코드 모달**이 열립니다.

```
┌──────────────────────────┐
│      학생 QR 코드         │
│                          │
│  홍길동 (20240001)       │
│  [지점명] (ADMIN 시)      │
│                          │
│     ┌──────────┐        │
│     │          │        │
│     │  QR CODE │        │
│     │          │        │
│     └──────────┘        │
│                          │
│  [인쇄]     [다운로드]    │
│                          │
│  [닫기]                  │
└──────────────────────────┘
```

- **[인쇄]**: QR 코드를 프린터로 인쇄
- **[다운로드]**: QR 코드 이미지를 파일로 다운로드

### 일괄 작업 (체크박스 선택 후)

| 버튼 | 설명 |
|------|------|
| **QR 일괄 다운로드** | 선택한 학생들의 QR 코드를 **ZIP 파일**로 일괄 다운로드 |
| **CSV 내보내기** | 선택한 학생들(또는 전체)의 출결 정보를 CSV 파일로 내보내기 |

### 정렬

- 컬럼 헤더를 클릭하면 해당 컬럼 기준으로 **오름차순/내림차순 정렬**이 토글됩니다.
- 정렬 방향은 헤더에 **화살표 아이콘**으로 표시됩니다.

### 페이지네이션

- **15건** 단위로 페이지가 나뉩니다.
- 이전/다음 버튼 및 페이지 번호 버튼으로 이동합니다.

## 5. 식사 신청 및 체크명단

학생들의 급식 신청 내역을 확인하고 급식 체크(태그)를 관리하는 페이지입니다.

### 필터 옵션

```
┌─────────────────────────────────────────────────────────────┐
│  [지점 ▼]  [학생명 ____]  [학번 ____]                        │
│  [날짜 📅 2026-04-10]              [검색]  [초기화]          │
└─────────────────────────────────────────────────────────────┘
```

| 필터 | 설명 |
|------|------|
| **지점** | 전체 또는 특정 지점 (ADMIN 전용) |
| **학생명** | 학생 이름 검색 |
| **학번** | 학번 검색 |
| **날짜** | 조회할 날짜 선택 (기본값: 오늘) |

### 테이블 컬럼

| 컬럼 | 정렬 | 설명 |
|------|------|------|
| **☐** | - | 체크박스 |
| **지점** | - | 소속 지점명 (ADMIN 전용) |
| **학생명** | ✅ | 학생 이름 |
| **학번** | ✅ | 학번 |
| **좌석** | ✅ | 배정된 좌석 번호 |
| **중식 신청** | ✅ | O 또는 "미신청" |
| **중식 체크** | ✅ | 클릭 가능한 상태 배지 |
| **석식 신청** | ✅ | O 또는 "미신청" |
| **석식 체크** | ✅ | 클릭 가능한 상태 배지 |

### 급식 체크 상태 표시

| 상태 | 표시 | 색상 | 클릭 동작 |
|------|------|------|----------|
| 신청 O + 체크 완료 | 태그 시간 (예: "12:30") | 🟢 초록 | 클릭 시 체크 취소 확인 |
| 신청 O + 미체크 | "미체크" | 🔴 빨강 | 클릭 시 체크 처리 확인 |
| 신청 X + 태그 감지 | "확인 필요" + 시간 | 🟠 주황 | - |
| 신청 X + 태그 없음 | "-" | - | - |

### 급식 체크/체크 취소

1. **"미체크"** 배지를 클릭합니다.
2. 확인 대화상자가 표시됩니다:
   > "홍길동 학생의 중식을 체크하시겠습니까?"
3. **[확인]**을 클릭하면 체크가 처리됩니다.
4. 처리 중 로딩 상태가 표시됩니다.
5. 성공 시 해당 셀이 즉시 업데이트됩니다.

2. 확인 대화상자:
   > "홍길동 학생의 중식 체크를 취소하시겠습니까?"

## 6. 휴대폰 미소지 관리

학생들의 휴대폰 미소지 신청 내역을 조회, 수정, 삭제하는 페이지입니다.

### 필터 옵션

```
┌─────────────────────────────────────────────────────────────┐
│  [지점 ▼]  [학생명 ____]  [학번 ____]                        │
│  [날짜 📅 2026-04-10]              [검색]  [초기화]          │
└─────────────────────────────────────────────────────────────┘
```

| 필터 | 설명 |
|------|------|
| **지점** | 전체 또는 특정 지점 (ADMIN 전용) |
| **학생명** | 학생 이름 검색 |
| **학번** | 학번 검색 |
| **날짜** | 조회 기준 날짜. **해당 날짜가 신청 기간에 포함되는 건**을 표시합니다. |

> **참고:** 날짜 필터는 "신청한 날짜"가 아니라 "해당 날짜가 신청 기간(시작일~종료일)에 포함되는지"를 기준으로 필터링합니다.

### 테이블 컬럼

| 컬럼 | 정렬 | 설명 |
|------|------|------|
| **☐** | - | 체크박스 |
| **지점** | - | 소속 지점명 (ADMIN 전용) |
| **학생명** | ✅ | 학생 이름 |
| **학번** | ✅ | 학번 |
| **좌석** | ✅ | 좌석 번호 |
| **학부모 연락처** | ✅ | 학부모 전화번호 |
| **메모** | ✅ | 메모 (20자 초과 시 "…"으로 말줄임) |
| **작업** | - | 수정/삭제 아이콘 버튼 |

### 행 클릭: 상세 모달

테이블 행을 클릭하면 **상세 모달**이 열립니다.

```
┌──────────────────────────────────┐
│      휴대폰 미소지 상세           │
│                                  │
│  학생명:      홍길동              │
│  학번:        20240001           │
│  좌석:        A-12               │
│  신청일:      2026-04-10         │
│                                  │
│  신청 기간:                       │
│    2026-04-10 ~ 2026-04-15      │
│    (또는 "휴대폰 없음")           │
│    (또는 "2026-04-10 ~ 퇴원까지") │
│                                  │
│  학부모 연락처: 010-1234-5678     │
│  메모:         독서실 집중 기간    │
│                                  │
│  [수정]  [삭제]                   │
│                                  │
│  [닫기]                          │
└──────────────────────────────────┘
```

### 신청 유형별 기간 표시

| 유형 | 표시 |
|------|------|
| **TEMPORARY** (기간 지정) | "시작일 ~ 종료일" |
| **PERMANENT** (퇴원까지) | "시작일 ~ 퇴원까지" |
| **NO_PHONE** (휴대폰 없음) | "휴대폰 없음" |

### 수정 기능

1. 상세 모달 또는 테이블의 **수정 아이콘**을 클릭합니다.
2. **수정 모달**이 열립니다.

```
┌──────────────────────────────────┐
│      휴대폰 미소지 수정           │
│                                  │
│  학부모 연락처:                   │
│  [010-1234-5678_____________]    │
│                                  │
│  메모:                           │
│  [독서실 집중 기간____________]    │
│                          25/50   │  ← 글자 수 카운터
│                                  │
│  [저장]  [취소]                   │
│                                  │
└──────────────────────────────────┘
```

- **학부모 연락처**: 텍스트 입력
- **메모**: 텍스트 입력, **최대 50자**, 실시간 글자 수 카운터 표시
- **[저장]** 클릭 시 수정 내용이 저장됩니다.
- **[취소]** 클릭 시 상세 모달로 돌아갑니다 (수정 내용 미반영).

### 삭제 기능

1. 상세 모달 또는 테이블의 **삭제 아이콘**을 클릭합니다.
2. 확인 대화상자가 표시됩니다:
   > "해당 휴대폰 미소지 신청을 삭제하시겠습니까?"
3. **[확인]** 클릭 시 삭제가 처리됩니다.

### 일괄 작업

| 버튼 | 설명 |
|------|------|
| **일괄 삭제** | 선택한 항목들을 한 번에 삭제. 확인 대화상자에 삭제 건수가 표시됩니다. |
| **CSV 내보내기** | 선택한 항목(또는 전체)을 CSV로 내보내기 |

### 페이지네이션

- **12건** 단위
- 페이지 번호는 한 번에 **최대 5개**씩 표시되며, 범위를 벗어나면 자동 이동됩니다.

| **학번** | 학번 검색 |

### 테이블 컬럼

### 경과시간 실시간 업데이트

- **이탈 중**인 학생의 경과시간은 **60초마다 자동 갱신**됩니다.
- 페이지를 새로고침하지 않아도 시간이 업데이트됩니다.

### 강제 복귀

1. 이탈 중인 학생의 **[강제 복귀]** 버튼을 클릭합니다.

3. **[확인]** 클릭 시 복귀 처리됩니다.
4. 해당 행의 상태가 "복귀"로 변경됩니다.

#### 일괄 강제 복귀

1. 체크박스로 여러 학생을 선택합니다.
2. **[N명 강제 복귀]** 버튼을 클릭합니다.
   - 선택된 학생 중 **이탈 중인 학생만** 카운트됩니다.
3. 확인 대화상자:
   > "N명의 학생을 강제 복귀 처리하시겠습니까?"
4. **[확인]** 클릭 시 일괄 복귀 처리됩니다.

### 일괄 작업

| 버튼 | 설명 |
|------|------|
| **N명 강제 복귀** | 선택한 이탈 중 학생 일괄 복귀 |

3. **[확인]** 클릭 시 거부 처리되고, 상태가 "거부"로 변경됩니다.

> **참고:** 이미 승인/거부된 요청에는 작업 버튼이 표시되지 않습니다.

### 날짜별 컬럼 (동적 생성)

- 선택한 날짜 범위에 해당하는 **각 날짜가 컬럼으로 표시**됩니다.
- 헤더 형식: "MM/DD(요일)" (예: "04/07(월)")
- 데이터 형식: "N시간 M분" 또는 "-" (데이터 없음)

### 가로 스크롤

- 날짜 범위가 넓으면 테이블이 **가로로 스크롤**됩니다.
- **학생명, 학번, 좌석, 합계 컬럼은 고정(Sticky)**되어 스크롤해도 항상 보입니다.

### 일괄 작업

| 버튼 | 설명 |
|------|------|
| **엑셀 다운로드** | 선택한 학생들(또는 전체)의 순공시간 데이터를 엑셀 파일로 다운로드 |

### 페이지네이션

- **15건** 단위
- 페이지 이동 시 테이블 상단으로 **자동 스크롤**됩니다.

### PIN 유효성 검사

- 숫자만 입력 가능합니다.
- 입력 시 **정확히 4자리**여야 저장 가능합니다.
- 4자리가 아닌 경우 필드 아래에 유효성 오류 메시지가 표시됩니다.

### 삭제

1. **[삭제]** 버튼을 클릭합니다 (빨간색 버튼).
2. 확인 대화상자:
   > "이 지점을 삭제하시겠습니까? 이 작업은 되돌릴 수 없습니다."
3. **[확인]** 클릭 시 지점이 삭제되고 설정 페이지로 이동합니다.

## 12. 권한별 기능 차이 (ADMIN vs USER)

시스템에는 두 가지 권한이 있습니다.

### ADMIN (최고 관리자)

| 기능 | 설명 |
|------|------|
| **지점 필터** | 모든 페이지에서 지점 선택 드롭다운 사용 가능 |
| **전체 보기** | "전체" 선택 시 모든 지점의 합산 데이터 조회 |
| **지점 컬럼** | 테이블에 "지점" 컬럼 표시 |
| **공지 지점 선택** | 공지 작성 시 게시할 지점 선택 가능 |
| **지점 관리** | 설정에서 지점 정보 추가/수정/삭제 |

### USER (일반 관리자)

| 기능 | 설명 |
|------|------|
| **자기 지점만** | 자기 소속 지점의 데이터만 조회 가능 |
| **지점 필터 없음** | 지점 선택 드롭다운이 표시되지 않음 |
| **지점 컬럼 없음** | 테이블에 지점 컬럼 미표시 |
| **공지 자동 지점** | 공지 작성 시 자동으로 자기 지점에 게시 |

## 13. 공통 UI 패턴

### 테이블 공통 기능

| 기능 | 설명 |
|------|------|
| **정렬** | 컬럼 헤더 클릭으로 오름차순/내림차순 토글. 현재 정렬 방향은 화살표 아이콘으로 표시 |
| **체크박스** | 헤더의 체크박스로 전체 선택/해제. 개별 행 체크박스로 개별 선택 |
| **페이지네이션** | 이전/다음 버튼 + 페이지 번호. 페이지별 표시 건수는 페이지마다 다름 |
| **빈 상태** | 데이터가 없을 때 "데이터가 없습니다" 등의 안내 메시지 표시 |
| **로딩 상태** | 데이터 로딩 중 로딩 인디케이터 표시 |

### 확인 대화상자

모든 위험한 작업(삭제, 상태 변경 등) 전에 확인 대화상자가 표시됩니다.

```
┌────────────────────────────┐
│                            │
│  정말 삭제하시겠습니까?      │
│                            │
│     [취소]    [확인]        │
│                            │
└────────────────────────────┘
```

- **confirm**: 확인/취소 선택 (boolean 반환)
- **alert**: 확인만 (안내 메시지)
- **prompt**: 텍스트 입력 (문자열 반환)

### CSV/엑셀 내보내기

- 파일 인코딩: **UTF-8 BOM** (엑셀 한글 호환)
- 파일명에 날짜 또는 맥락 정보 포함
- 형식: 헤더 행 + 데이터 행
- 선택한 항목만 또는 전체 데이터 내보내기 가능

### 글자 수 카운터

- 제목, 내용, 메모 등 길이 제한이 있는 입력 필드에 **실시간 글자 수 카운터**가 표시됩니다.
- 형식: `현재 글자 수 / 최대 글자 수` (예: "85/100")

### 세션 유지

- 로그인 정보: `sessionStorage`에 저장
  - `isLoggedIn`: 로그인 여부
  - `adminName`: 관리자 이름
  - `storeName`: 소속 지점명
  - `adminRole`: 권한 (ADMIN / USER)
- **401 오류** 시 자동 토큰 갱신 시도
- 갱신 실패 시 로그인 페이지로 리다이렉트
